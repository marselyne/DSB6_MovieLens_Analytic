# MovieLens Analytics

Проект по анализу данных MovieLens с использованием Python, API, парсинга и обработки данных.

## 📌 О проекте

В рамках проекта был реализован набор инструментов для анализа данных о фильмах из датасета MovieLens.

Проект включает:
- обработку CSV-данных
- анализ жанров и фильмов
- работу с IMDb
- web scraping
- enrichment datasets
- unit testing

---

## 🚀 Реализованный функционал

### 🎬 Анализ фильмов

Реализованы методы:
- распределение фильмов по годам
- распределение по жанрам
- поиск фильмов с наибольшим количеством жанров
- анализ совместной встречаемости жанров

В проекте используется обработка данных MovieLens и работа с коллекциями Python. 

---

### 🌐 Работа с IMDb

Реализовано:
- получение данных с IMDb
- парсинг HTML через BeautifulSoup
- работа с HTTP-запросами
- enrichment movie data

Получаются:
- режиссёры
- бюджеты
- сборы
- длительность фильмов



---

### 📊 Movie Analytics

Реализован анализ:
- топ режиссёров
- самые дорогие фильмы
- самые прибыльные фильмы
- стоимость минуты фильма
- продолжительность фильмов

---

### 🧪 Unit Testing

Написаны тесты с использованием pytest:
- проверка enrichment methods
- проверка genre analytics
- тестирование обработки данных
